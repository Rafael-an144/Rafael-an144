## Featured project

### [Municipal AI Diagnosis](https://github.com/cidadesdofuturo/smart-city-diagnostic-ai)

An AI-powered system that analyzes municipal indicators and generates technological maturity assessments and institutional reports.

The project uses:

- Python
- LangChain
- Google Gemini
- Semantic embeddings
- FAISS vector search
- Retrieval-Augmented Generation
- Pandas and Pydantic
- Automated Word and PDF report generation

The system was designed to support municipalities in identifying strengths, challenges and opportunities related to innovation, digital transformation and smart-city development.

## Current projects

### GeoAI Agent

A framework for creating AI agents capable of:

- Understanding territorial questions in natural language
- Selecting geospatial tools automatically
- Consulting geographic datasets
- Performing spatial operations
- Generating maps and analytical responses

### Environmental Geodata Assistant

A conversational system designed to answer questions such as:

- Which rivers cross a municipality?
- Which protected areas are located near a project?
- What percentage of a territory is environmentally protected?
- Which communities, roads or water bodies may be affected by an intervention?

### Municipal Data Pipeline

A reproducible pipeline for:

- Collecting public municipal data
- Cleaning and standardizing indicators
- Performing automated analyses
- Creating charts and maps
- Generating technical reports
